# Onscreen Rickroll
Shows 3 frames of the famous Rickroll on the display of the device.

## How to set up and use:
**First way:** Copy over '_autorun.ds_' and all the PNG files on the SD card. When you plug in the device, the animation will run automatically, _everytime_.

**Second way:** Copy over '_rickroll-display.ds_' and all the PNG files on the SD card. When you plug in the device, the animation has to be started by executing '_rickroll-display.ds_' in its web interface.

## **Note:**
This example is purely visual, it doesnt do anything else other than Rickroll you.
